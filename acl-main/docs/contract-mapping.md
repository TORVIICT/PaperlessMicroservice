## 4. Error Mappings

### 4.1 OCR → FE Error Envelope

| OCR Code | OCR Transport | FE Code | Status |
|----------|---------------|---------|--------|
| `INVALID_FILE` | HTTP 400 | `INVALID_FILE` | DOC (codes) / body has no `code` (INC-11) |
| `UNSUPPORTED_MIME_TYPE` | HTTP 415 | `UNSUPPORTED_FILE_TYPE` | DOC / INF |
| `PASSWORD_PROTECTED_PDF` | Job `failed` | `OCR_PROCESSING_FAILED` | **GAP** (D-36, D-42) |
| `CORRUPT_DOCUMENT` | Job `failed` | `OCR_PROCESSING_FAILED` | **GAP** (D-36, D-42) |
| `PROCESSING_TIMEOUT` | Job `failed` / HTTP 504 | `OCR_PROCESSING_FAILED` | **GAP** (D-36, D-42) |
| `ENGINE_ERROR` | Job `failed` / HTTP 500 | `OCR_PROCESSING_FAILED` | **GAP** (D-36, D-42) |
| *(no OCR code)* file > 50 MB | *(none)* | `FILE_TOO_LARGE` | **GAP**: ACL enforces 50 MB (D-35) |
| *(no OCR code)* 404 job | HTTP 404 | `DOCUMENT_NOT_FOUND` | INF |
| *(no OCR code)* artifact not ready | 404 on archive/thumbnail | `DOCUMENT_NOT_READY` | INF — OCR returns 404 for both "missing" and "not yet" |
| OCR unreachable / `503` / socket error / timeout | — | `SERVICE_UNAVAILABLE` | INF |
| HTTP status per FE code | — | — | **GAP** (D-42) |

**Error Envelope:** FE format `{code, message, documentId, details}` (not RFC 9457). D-36/D-42.
