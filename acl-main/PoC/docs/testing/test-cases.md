# Test Cases

## Scope and sources

- **Scope:** the ACL service of `PoC/src/OcrAcl.Api`, exercised through its two contract endpoints (`POST /api/ocr/documents`, `GET /api/ocr/health`) and through the three layers in isolation.
- **Sources:** every expected result cites a contract clause (`CT-xx`), a documented decision (`D-xx`) or an assumption (`A-xx`) of `PoC/docs/contract-analysis.md` and `PoC/docs/technical-decisions.md`. Simulated values (`text`, `pageCount`, `confidence`) are only asserted through the properties the contract guarantees (type, range, presence) and through determinism, never as constants copied from the implementation (TS-02, D-33).
- **Sizing:** 78 cases. A typical single-endpoint contract is expected to produce 40-80 cases; this contract has two endpoints and five required request fields plus a complete error table, which is inside that range. No size justification is required.
- The matrix is created in Phase 2 with every status `Not Run` (TS-16), completed with the automated test names in Phase 3 and filled with real results in Phase 4.
